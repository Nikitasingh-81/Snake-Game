# Snake-Game

• Fully playable, browser-based classic Snake game reimagined with a modern neon cyberpunk aesthetic

• Single HTML file - No frameworks, no dependencies, pure HTML5 Canvas and JavaScript

• Dark Cyberpunk UI - Deep space background with subtle CRT scanline effects for a retro-futuristic feel

• Glowing Cyan Grid - Soft shadow blur creates a neon wireframe look

• Neon Pink Snake - Features a gradient tail, per-segment glow, and directional eyes that change based on movement

• Pulsing Green Food - Glowing food block with a dynamic radial halo and pulse animation

• Particle Effects - Neon particle explosion bursts when food is eaten

• Score Tracking - Real-time score counter and persistent high score tracker

• Game Over Screen - Stylized neon overlay with a blinking restart prompt

• Keyboard Controls - Arrow keys or WASD to steer, Spacebar to restart after game over

• Smart Gameplay Logic - Anti-reversal mechanism prevents instant self-collision on opposite key presses

• Smooth Performance - Optimized game loop using requestAnimationFrame

• Privacy & Offline - 100% client-side processing, no server uploads, works completely without internet

• Zero Installation - Just save the HTML file and open it in any modern browser (Chrome, Firefox, Safari, Edge). No installation, no build process
